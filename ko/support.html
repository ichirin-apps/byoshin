Byoshin은 iOS의 실시간 현황을 이용해 초를 표시합니다. iOS에서 정해져 있어 앱에서 바꿀 수 없는 부분도 있어, 자주 묻는 질문을 모았습니다.

하루 종일 초를 표시하려면?

단축어 앱의 자동화로 6시간마다 초 표시를 다시 시작합니다(Byoshin Pro 기능). 앱의 ‘항상 표시 설정’에서 사용 중인 iOS에 맞는 순서를 한 화면씩 안내합니다.

  • 단축어 앱에서 자동화 → + → 특정 시간
  • 시간을 0:00, 반복을 ‘매일’로 하고 ‘즉시 실행’ 선택
  • 동작 ‘초 표시 시작’ 추가(‘Byoshin’으로 검색)
  • 6:00, 12:00, 18:00도 같은 방법으로 만들기(총 4개)

설정이 되었는지 확인하려면?

메인 화면의 ‘항상 표시 설정 n/4’를 탭하면 4개 시간별 동작 상태(✓)를 확인할 수 있습니다. 설정한 시간이 지나 자동화가 실행되면 ✓가 표시됩니다.

초가 표시되지 않아요

설정 앱 → Byoshin → 실시간 현황이 켜져 있는지 확인해 주세요. 꺼져 있으면 iOS가 표시를 허용하지 않아 초를 표시할 수 없습니다.

켠 다음 Byoshin을 열고 ‘표시 시작’을 탭하면 표시됩니다.

8시간 정도 지나면 표시가 사라져요

iOS에서는 실시간 현황을 연속으로 표시할 수 있는 시간이 최대 8시간으로 정해져 있습니다. 그래서 어떤 앱이든 8시간 정도 지나면 표시가 끝납니다.

‘항상 표시 설정’에서 자동화를 만들어 두면 6시간마다 자동으로 다시 표시하므로 하루 종일 초를 볼 수 있습니다(Byoshin Pro 기능). 자동화를 쓰지 않을 때는 끝나기 조금 전에 오는 알림을 탭하면 다시 표시할 수 있습니다.

잠금 화면에서만 숨길 수 있나요?

iOS에서는 Dynamic Island와 잠금 화면의 실시간 현황이 한 세트로 되어 있어, 둘 중 하나만 표시할 수 없습니다.

그 대신 Byoshin은 잠금 화면 표시를 가는 한 줄의 차분한 디자인으로 만들어 배경화면을 가리지 않도록 했습니다.

잠금 화면에서 밀어서 지웠더니 초가 멈췄어요

잠금 화면에서 실시간 현황을 옆으로 밀면 iOS가 그 표시를 종료합니다. 한 번 종료된 표시는 다음 자동화가 실행될 때까지 돌아오지 않습니다.

바로 다시 표시하려면 Byoshin을 열고 ‘표시 시작’을 탭하거나, 위젯 또는 제어 센터의 버튼으로 다시 시작할 수 있습니다.

다른 앱의 실시간 현황과 함께 있으면 초가 작아지거나 보이지 않아요

실시간 현황이 2개 이상일 때 어느 것을 크게, 어느 것을 작게(둥근 아이콘만) 표시할지는 iOS가 자동으로 정합니다. 앱 쪽에서 순서를 지정할 수는 없습니다.

지도 내비게이션이나 타이머 등을 사용하는 동안에는 그쪽이 우선될 수 있지만, 다른 앱의 표시가 끝나면 초는 원래 크기로 돌아옵니다.

Byoshin을 열고 있는 동안 Dynamic Island에 초가 나오지 않아요

iOS에서는 지금 열려 있는 앱 자신의 실시간 현황은 Dynamic Island에 표시되지 않습니다.

홈 화면이나 다른 앱으로 전환하면 바로 표시됩니다. Byoshin을 열고 있는 동안에는 화면의 큰 숫자로 초를 확인할 수 있습니다.

자동화가 실행되지 않는 것 같아요

단축어 앱에서 다음을 확인해 주세요.

  • ‘즉시 실행’이 선택되어 있는지(‘확인 후 실행’이면 자동으로 표시되지 않습니다)
  • 동작에 ‘실행할 때 열기’가 보이면 꺼져 있는지
  • 0:00, 6:00, 12:00, 18:00의 4개가 만들어져 있고 각각 켜져 있는지

항상 표시는 Byoshin Pro 기능입니다. Byoshin의 ‘항상 표시 설정 상태’에서 시간별로 동작하는지 확인할 수 있습니다(✓는 설정한 시간이 지난 후 표시됩니다).

Dynamic Island가 없는 기종에서도 쓸 수 있나요?

네, 사용할 수 있습니다. Dynamic Island가 없는 기종에서는 잠금 화면과 알림 센터의 실시간 현황으로 초를 표시합니다. 홈 화면·잠금 화면 위젯에서도 초를 볼 수 있습니다(위젯은 Byoshin Pro 기능입니다).

초가 1초 정도 어긋나 보일 때가 있어요

초 숫자는 iPhone의 시계를 바탕으로 iOS가 그립니다. 상태 막대의 시간과 실시간 현황은 iOS 안에서 서로 다른 타이밍에 화면이 갱신되기 때문에, 분이 바뀌는 순간 등에 아주 조금 어긋나 보일 수 있습니다.

시간 자체가 어긋난 것은 아니므로 안심하고 사용하셔도 됩니다. 또한 저전력 모드이거나 화면이 어두워져 있을 때는 iOS가 표시 갱신을 줄일 수 있습니다.

배터리에 영향이 있나요?

초는 iOS가 그리고 Byoshin은 백그라운드에서 계속 실행되지 않으므로 영향은 작게 유지됩니다.

다만 실시간 현황을 하루 종일 표시하는 만큼, 표시하지 않을 때보다 전력을 조금 더 사용합니다. 신경 쓰이면 앱에서 ‘표시 중지’로 언제든 멈출 수 있습니다.

구입 내역을 복원하려면?

Byoshin 오른쪽 위의 설정 버튼 → ‘구입 내역 복원’을 탭해 주세요. 구입할 때와 같은 Apple 계정으로 로그인되어 있어야 합니다. Byoshin Pro는 한 번 구입으로, 구독이 아닙니다.
